# Установка трёх юридических проектов ChatGPT

**Актуальная версия:** 23.11.2026. **Режим:** короткие инструкции в настройках + отдельные полные источники проекта. **Длина каждой инструкции — менее 8000 символов.**

## Шаг 1. Инструкции проекта

В настройках **каждого** проекта ChatGPT замени прежний текст целиком на текст подходящего файла:

| Проект ChatGPT | Вставить в поле «Инструкции» |
|---|---|
| Юридическая проверка книги | [01-kniga.md](01-kniga.md) |
| Реклама и маркировка — РФ | [02-reklama-markirovka.md](02-reklama-markirovka.md) |
| Юридическое сопровождение онлайн-бизнеса — РФ | [03-online-business.md](03-online-business.md) |

Не вставляй в поле инструкций общий регламент, полные SKILL.md или длинные нормативные справочники: они предназначены для **«Источников»**.

## Шаг 2. Общий файл в «Источники» каждого проекта

Единственный редактируемый оригинал: **[docs/file-delivery-workflow.md](../file-delivery-workflow.md)**.

Для удобного поиска скачай его как файл **`00_Правила_сохранения_файлов.md`**, **не изменяя содержимое**, и добавь отдельной копией в раздел **«Источники»** каждого из **трёх** проектов ChatGPT. Номер `00` ставит документ первым в алфавитном списке. Это **экспортная копия**, а не второй независимый оригинал GitHub.

В самих коротких инструкциях прописана обязанность прочитать этот источник целиком перед созданием итоговых файлов, проверить его актуальность и выполнять регламент. Ссылка GitHub без прочтения **не является** доказательством подключения источника.

## Шаг 3. Специализированные источники

- **Книга:** `skills/yur-proverka-temy/SKILL.md`; актуальная версия проверяемой темы книги; необходимые источники права и правила определения версии темы из репозитория книги.
- **Реклама:** `skills/ru-reklama-online/SKILL.md`, применимые тексты ФАС и реестр/ссылки на нормативные документы.
- **Онлайн-бизнес:** `skills/ru-onlain-shkola-dokumenty/SKILL.md`, `skills/ru-dogovory-podryadchiki/SKILL.md`, `skills/ru-shablony-dokumentov/SKILL.md`, `skills/ru-audit-lendinga/SKILL.md`, `skills/ru-monitor-izmeneniy/SKILL.md`.

Источник `00_Правила_сохранения_файлов.md` **один и тот же** для всех проектов. Не создавай различные редакции этого файла для книги, рекламы и бизнеса.

## Шаг 4. Обновление

1. Меняй регламент **только** в `docs/file-delivery-workflow.md` через обычный GitHub PR/merge.
2. Обнови экспортную копию `00_Правила_сохранения_файлов.md` в источниках всех трёх проектов; не оставляй старый и новый файл одновременно.
3. При изменении кратких инструкций **вручную** замени текст в настройках нужного проекта. Изменение GitHub не обновляет его автоматически.
4. При изменении SKILL.md обнови подключённую копию этого навыка и убедись, что актуальная версия действительно доступна.
5. При отсутствии доступа к исходным файлам помощник должен честно отметить ограничение, а не объявлять инструкции подключёнными или результаты сохранёнными.

**Разделение по предмету:** только юридические вопросы онлайн-проектов. ТСЖ, ЖКХ, недвижимость и другие посторонние офлайн-проекты исключены.
