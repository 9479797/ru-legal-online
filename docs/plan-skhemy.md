# Карта целей и путей схемы продвижения

Состояние на 20.11.2026. С 20.11.2026 схема рассчитана на любые онлайн-проекты, не только на проект для беременных: примеры в текстах общие, медицинские правила даны для тех, чья тема касается здоровья. Порядок целей на сайте: 1, 2, 3, 4, 5, 6, 7 по номерам ниже; разделы файла идут в порядке создания. Страница: `site/index.html`, данные: `site/data.js`.

Путь в схеме: **старт → связка (как переводим человека) → где продаём → итог** (можно, нельзя, ответственность, список дел перед первым постом). Форма работы (самозанятая, ИП, ООО) меняет штрафы и список дел, пути от неё не зависят.

Max исключён из проекта по решению автора (19.11.2026): аудиторию туда не переводим и не дробим.

## Планы (на потом)

- **Тема проекта.** Поле «Тема проекта», которое подключает правила ниши: финансы и инвестиции (реклама финансовых услуг, запрет гарантий дохода), детская тема (возрастная маркировка, согласие родителей на данные детей), психология (граница консультации и психотерапии), красота и фитнес (БАДы, медицинские обещания). - **Площадки для услуг:** Авито Услуги, Профи.ру — для консультаций и сопровождения.
- **Max.** Для проекта пользователя исключён; для широкой аудитории это разрешённая российская площадка с реестром РКН. Решение — за пользователем.

- **Публичный сайт.** Сейчас — личная страница Claude. Для широкой аудитории — GitHub Pages из папки `site` или свой домен; понадобятся автор, контакт для замечаний и дата обновления на видном месте.
