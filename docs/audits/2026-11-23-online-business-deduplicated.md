# Единый реестр замечаний — юридическое сопровождение онлайн-бизнеса РФ

**Дата аудита:** 23.11.2026. **Статус:** предложения для утверждения; ни один пункт сам по себе не устанавливает нарушение конкретного бизнеса. За семь этапов было 92 наблюдения, включая дубли. В этом реестре 50 самостоятельных групп замечаний (27 высокого и 23 среднего приоритета); они сгруппированы по самостоятельным причинам.

**Приоритет:** В — высокий; С — средний. **Связанные файлы:** online = ru-onlain-shkola-dokumenty, templates = ru-shablony-dokumentov, contracts = ru-dogovory-podryadchiki, landing = ru-audit-lendinga, monitor = ru-monitor-izmeneniy. Классификация отмечает исходное замечание; перед применением к конкретному случаю требуется проверка юридического состава и фактов.

## Порядок принятия и границы

1. Сначала исправить неверные универсальные правила и добавить пропущенные обязательные нормы (A01, B01–B03, C01–C03, D01–D05, E01–E04).
2. Затем исправить дубли в связанных навыках и добавить алгоритмы проверки фактической модели исполнения, расчётов и обработки данных.
3. Проверять применимость каждой нормы к модели: тип продукта, статус продавца, потребитель/бизнес, платежи, лицензия, сайт, данные, доступ. Не подменять реальный договор заголовком «курс» или «лицензия».
4. Один **плановый мониторинг раз в месяц**, без более частых фоновых проверок; проверка источников по непосредственному юридическому запросу не считается плановым мониторингом.
5. Не смешивать рекламную маркировку и содержание медицинской книги с юридическим режимом продажи онлайн-продукта. Внешние рекламные положения передавать отдельному проекту.
6. Изменения только в рабочей ветке через PR. Без merge до утверждения пользователя; после merge вручную обновить копии навыков ChatGPT.
