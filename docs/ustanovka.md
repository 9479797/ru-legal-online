# Как подключить навыки в Claude

Репозиторий хранит исходники. Сами навыки в Claude подключаются сохранением.

1. Откройте чат с Claude и попросите: «Сохрани навык из skills/<имя>/SKILL.md репозитория ru-legal-online».
2. Claude покажет карточку навыка; нажмите «Сохранить».
3. Если навык уже был сохранён раньше, карточка покажет изменения и заменит старую версию.

После каждого слияния правок в `main` повторите сохранение для изменённых навыков (список в `CHANGELOG.md`).

## Работа из других ИИ (ChatGPT и др.)

Файл `SKILL.md` можно передать как инструкцию: вставить в настройки проекта или приложить к чату. Правила для агентов в `AGENTS.md`.
