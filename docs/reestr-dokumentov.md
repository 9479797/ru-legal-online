# Реестр документов проекта

Документы ведомств и судов, на которые опираются навыки, кроме законов (законы — в `docs/istochniki.md`). Состояние на 20.11.2026.

Контрольные суммы имеют два формата: для `docs/fas-teksty/*.txt` — SHA-256 **нормализованного текста** (`scripts/sravnit_tekst.py`), а для `docs/normy-teksty/*.txt` — SHA-256 **исходного файла**, как в `docs/sverka-norm-2026-11-20.md`. Периодическая техническая проверка сравнивает суммы с реестром; она не устанавливает актуальность закона.

Статус:
- **текст есть** — полный текст в `docs/fas-teksty/`, сверка по контрольной сумме;
- **конспект** — есть только конспект или ссылка в навыке;
- **нужен текст** — документ найден, текст ещё не получен.

## Как получить текст

1. Найти документ в КонсультантПлюс (некоммерческая версия открывается по рабочим дням с 20:00 до 24:00 по Москве, в выходные круглосуточно).
2. Открыть полный текст и нажать «Сохранить в Word» (кнопка W над текстом).
3. Прикрепить .docx в чат. Claude сохраняет текст в `docs/fas-teksty/`, считает контрольную сумму и делает конспект.
