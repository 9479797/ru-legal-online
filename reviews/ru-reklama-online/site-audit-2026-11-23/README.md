## Как восстановить и открыть

1. Скачать ZIP из этой папки или с Google Диска.
2. Полностью распаковать его.
3. Открыть `reklama-local/index.html` двойным щелчком. Установка и сервер не нужны.
4. Прочитать `README.txt`, `CHANGELOG.local.md`, `SOURCES.md` и `docs/plan-skhemy.md` внутри архива.

ZIP содержит весь исходный код локальной версии, включая `data.js`, `book-ui.js`, обе HTML-страницы и `markirovka.js`. Надпись «GitHub не изменён» внутри ZIP относится к моменту изготовления локального варианта до этого резервного коммита; не означает замену канонической версии сайта.
