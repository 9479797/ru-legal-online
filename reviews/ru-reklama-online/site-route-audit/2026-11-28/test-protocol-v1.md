# Протокол сквозной проверки реальных рекламных связок — версия 0.1
**Дата:** 28.11.2026. **Сайт:** рабочая v20.6. **Статус:** на согласовании, не завершённая юридическая приёмка.

## 1. Правила проверки

В каждом испытании фиксируются **входной креатив (текст/видео), фактический ресурс и URL, дата, аудитория РФ, стороны, коммерческие отношения, объект рекламирования, цель и доказательства**. Отсутствующий существенный факт даёт статус «недостаточно данных», а не предположительно законное размещение.

Каждая связка проходит четыре самостоятельных теста:
1. **Классификация содержания:** информация или реклама? По ст.3 38-ФЗ и разъяснениям ФАС; обязательные признаки в совокупности, не только слово «купить».
2. **Допустимость:** выбранная площадка, дата, объект рекламы, специальные запреты, регистрация канала РКН при применимости. Не использовать пометку erid для «легализации» запрещённой рекламы.
3. **Процедура, если это реклама:** рекламодатель/распространитель/посредник, маркировка, ОРД/ЕРИР, акт/отчётность, сбор при применимости; отделить требования договора и сервиса.
4. **Фактический путь:** воспроизводимость URL/бота/магазина/подписки, соответствие обещаний содержимому страницы, наличие рабочего итога. Открытие страницы не означает покупку.

Критерий **пройдено**: исходные доказательства сохранены, закон/позиция/правила площадки привязаны к конкретному выводу с датой сверки, все блокирующие неопределённости закрыты, есть проверенный результат (можно / после исправления / нельзя / недостаточно данных), и автоматический тест не противоречит эксперту. Проверка структуры без источников не закрывает юридическую карточку.

## 3. Реестр доказательств каждого прогона
Нужны поля: `case_id`, `method_id`, `publication_date`, `platform_actual`, `audience_RF`, `advertised_object`, `creative_ref`, `commercial_relationship`, `advertiser`, `distributor`, `destination_test`, `law_refs`, `agency_position_refs`, `service_rules_refs`, `date_sources_checked`, `classification`, `risk`, `decision`, `blockers`, `corrective_steps`, `reviewer`, `review_date`.

Без материалов реального проекта тест T01–T22 — **проект протокола**, а не зарегистрированный успешно пройденный юридический кейс.

## 4. Критерии выпуска цели «Текстовые материалы»
- 86/86 методов представлены в паспортах и 774/774 ячейки учтены технически.
- У всех показанных условных направлений есть критерий подтверждения формата ссылки/товара; ни один неподтверждённый результат не обозначается разрешённым.
- 9 критичных методов проверены по нормам и контексту публикации; неверные выводы исправлены до выпуска.
- Все даты действия норм, ограничения площадок, регистрация РКН, ОРД/ЕРИР и применимость сбора сверены по выбранным реальным случаям.
- По каждому случаю сохраняются доказательства, а статус нельзя перевести в «проверено» без нормативного основания и подписи проверяющего.
- При содержательно спорных правилах система выводит ограничение и предлагает проверку у профильного юриста, а не имитирует окончательную определённость.
