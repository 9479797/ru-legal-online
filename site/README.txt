КАК ОТКРЫТЬ
1. Полностью распакуйте ZIP в отдельную папку.
2. Откройте index.html двойным щелчком в браузере.
3. Оставьте остальные файлы рядом: они нужны сайту.
Установка, терминал и локальный сервер не требуются. Скрипты и шрифты локальные.
Для внешних правовых источников нужен интернет.

ЧТО ПОСМОТРЕТЬ
Первая цель: «Продать текстовые материалы: памятку, гайд, книгу».
Два раздела: продвижение / продажа в рекламном контексте.
Исполнение заказа исключено. Форматы: цифровой файл / печатная книга.
Бесплатный фрагмент — необязательный этап, не отдельная цель.

В VK: ответ на входящий вопрос; переход из поста или VK Рекламы на маркетплейс.
Для цифрового файла в каталоге VK показана необходимость проверить правила.
Это не установленный законодательный запрет. Для печатной книги путь сохранён.
Переход на маркетплейс условен: нужен конкретный сервис и поддерживаемый формат.
Донат остаётся подпиской; текущие условия подключения требуют проверки.

В продаже отдельно выбирается место предложения. Проверяется рекламная сторона
страницы/карточки, а не договор, касса или выполнение заказа.
Бот и переход на сайт различаются. Копия видео не объявляется переносом зрителей.
Кнопки сохраняют выбранный итог в HTML либо через печать/PDF.
Выбор сохраняется, если браузер разрешает локальное хранение для файлов.
