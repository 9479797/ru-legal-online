# Юридические навыки онлайн-проекта (право РФ)

Общая юридическая база для ChatGPT, Claude и других ИИ-помощников по российскому праву **онлайн-проектов**: содержание электронной книги, интернет-реклама и маркировка, продажа цифровых продуктов, онлайн-школы, лендинги, документы и договоры с исполнителями.

Навыки не заменяют юриста. Они разбирают ситуацию, показывают риски со ссылками на нормы и готовят черновики документов.

## Как устроена работа: три проекта ChatGPT и один GitHub

**GitHub — единый источник файлов**, а не отдельный чат и не автоматически обновляемый набор инструкций ChatGPT. Здесь хранятся исходники семи навыков, ссылки на нормативные документы, правила изменений, вспомогательные схемы и история правок. В профиле ChatGPT предполагается создать **три отдельных проекта** с разными инструкциями и набором релевантных файлов. Проекты ещё нужно создать и настроить вручную; наличие шаблонов в GitHub не означает, что они уже существуют в ChatGPT.

**Границы проекта:** сюда **не входят ТСЖ, ЖКХ, управление домами, жилищное право, недвижимость и любые посторонние офлайн-проекты**. Регистрация ИП или юридического лица рассматривается лишь применительно к конкретному онлайн-бизнесу. Наличие навыка по договорам с блогерами не делает второй и третий проекты взаимозаменяемыми: рекламную маркировку проверяет второй, общие договорные условия — третий.

### Как распределить связанные вопросы

- **Текст книги** (достоверность юридических формулировок, ответственность автора, лекарства и источники) → «Юридическая проверка книги». При полной проверке темы навык предусматривает **два полных Word-файла**: предложенную редакцию и визуальный редлайн. Решение о медицинской рецензии принимает автор; неподтверждённые опасные медицинские сведения не считаются готовыми к публикации.
- **Публикация рекламы книги или курса**, её площадка, маркировка, erid, рекламный договор в части размещения и отчётности → «Реклама и маркировка — РФ».
- **Продажа книги или курса**, срок доступа, оферта, кассовые чеки, возвраты, персональные данные и юридическая проверка страницы оплаты → «Юридическое сопровождение онлайн-бизнеса — РФ».
- При смешанном запросе разбирай части по их предмету. **Ссылаться на смежный навык можно, но нельзя объявлять весь смешанный вопрос проверенным только одним навыком.**

### Как подключить к ChatGPT

1. Создать **три проекта** в ChatGPT с указанными названиями.
2. Для каждого открыть одноимённый файл из **docs/chatgpt-projects/** и перенести текст в **инструкции соответствующего проекта ChatGPT**.
3. Предоставить проекту доступ к актуальным файлам нужных навыков через доступный коннектор GitHub или приложить копии **SKILL.md** и необходимые справочники. **Ссылка в настройках сама по себе не гарантирует, что ChatGPT прочитает её содержимое**: перед правовым заключением помощник должен действительно открыть нужный источник.
4. Если навык, шаблон или правовая норма обновились в GitHub, повторно синхронизировать вложенные копии и инструкции проектов ChatGPT вручную. **Автоматической синхронизации между GitHub, ChatGPT Projects и установленными навыками Claude нет.**
5. Для Claude установка навыков отдельно описана в [docs/ustanovka.md](docs/ustanovka.md).

**Приоритет источников при юридическом анализе:** действующая официальная норма и проверенные документы на дату обращения; затем применимые инструкции конкретного навыка; затем вспомогательные справки и сохранённые заметки. Содержимое репозитория не заменяет актуальной проверки законодательства. Не вносить в GitHub личные данные клиентов, пароли и токены.

## Как обновлять

1. Пункты, которые часто меняются, помечены `[ПРОВЕРЯТЬ]`. Навыки проверяют их поиском при каждом ответе.
2. Раз в месяц монитор изменений сверяет навыки с новостями права и предлагает правки отдельной веткой.
3. Правка вносится в `SKILL.md`, записывается в `CHANGELOG.md`, проверяется `python3 scripts/proverka.py` и попадает в `main` через pull request.
4. После слияния изменённый навык заново сохраняют в Claude (см. `docs/ustanovka.md`).
5. Если обновлены инструкции проектов ChatGPT или используемые ими навыки, примените изменения в настройках соответствующих проектов вручную; GitHub не синхронизирует их автоматически.

## Схема продвижения

Страница `site/index.html` — интерактивная схема для эксперта любого онлайн-проекта (с 20.11.2026 тексты не привязаны к теме беременности; правила о медицине даны для тех, чья тема касается здоровья): как вы оформлены (без статуса, самозанятый, ИП на НПД, ИП, ООО, АНО) и цель, площадка старта, связки между площадками, риск каждого шага, что можно и нельзя, штрафы для выбранного статуса. Опубликована как личная страница Claude: https://claude.ai/artifact/6xEje39yViGNiq5acpgC2C.

Всё содержимое лежит в `site/data.js`, страницу для наполнения менять не нужно. Правила те же, что для навыков: норма меняется только с источником и записью в `CHANGELOG.md`, неуточнённая сумма помечается `verify: true` и показывается на странице с пометкой «сверить». После правки: `python3 scripts/proverka.py` (проверяет и данные схемы), при правке страниц — ещё `python3 scripts/proverka_brauzer.py`, затем страницу публикуют заново. Риск и штрафы площадок стартового шага задаются один раз в `PLATFORMS` в начале `site/data.js`.

Локально страница открывается двойным щелчком по `site/index.html`.
