# Юридические навыки онлайн-проекта (право РФ)

Навыки для Claude, которые помогают разбираться в юридических вопросах онлайн-проекта для беременных и мам: реклама в каналах и у блогеров, документы онлайн-школы, лендинги, договоры с исполнителями, шаблоны документов, проверка глав книги.

Навыки не заменяют юриста. Они разбирают ситуацию, показывают риски со ссылками на нормы и готовят черновики документов.

## Как обновлять

1. Пункты, которые часто меняются, помечены `[ПРОВЕРЯТЬ]`. Навыки проверяют их поиском при каждом ответе.
2. Раз в месяц монитор изменений сверяет навыки с новостями права и предлагает правки отдельной веткой.
3. Правка вносится в `SKILL.md`, записывается в `CHANGELOG.md`, проверяется `python3 scripts/proverka.py` и попадает в `main` через pull request.
4. После слияния изменённый навык заново сохраняют в Claude (см. `docs/ustanovka.md`).

## Схема продвижения

Страница `site/index.html` — интерактивная схема для эксперта: форма работы и цель, площадка старта, связки между площадками, риск каждого шага, что можно и нельзя, штрафы для выбранной формы работы. Опубликована как личная страница Claude: https://claude.ai/artifact/6xEje39yViGNiq5acpgC2C.

Всё содержимое лежит в `site/data.js`, страницу для наполнения менять не нужно. Правила те же, что для навыков: норма меняется только с источником и записью в `CHANGELOG.md`, неуточнённая сумма помечается `verify: true` и показывается на странице с пометкой «сверить». После правки: `python3 scripts/proverka.py` (проверяет и данные схемы), затем страницу публикуют заново.

Локально страница открывается двойным щелчком по `site/index.html`.
